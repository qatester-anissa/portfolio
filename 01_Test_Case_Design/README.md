# 🧩 Test Case Design

This section contains examples of **test case design techniques** I’ve practiced for different projects and features.  
Each file demonstrates how I identify test conditions, write detailed test steps, and define expected results.

---

## 🎯 Objectives
- Practice writing **clear, structured test cases**
- Use various **test design techniques**:
  - Equivalence Partitioning
  - Boundary Value Analysis
  - Decision Table Testing
  - Positive & Negative Testing
- Showcase real-world examples of manual test documentation
